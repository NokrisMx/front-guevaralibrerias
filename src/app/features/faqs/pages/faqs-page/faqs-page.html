Preguntas Frecuentes

Guevara Librerías es un proyecto demostrativo creado con Angular, Tailwind CSS, DaisyUI y .NET Web API para mostrar una experiencia moderna de ecommerce enfocada en una librería digital.

¿Guevara Librerías es una tienda real?

No. Este sitio fue desarrollado únicamente con fines demostrativos y educativos. No realiza ventas reales ni procesa pagos.

¿Qué tecnologías fueron utilizadas?

El frontend fue desarrollado con Angular 21, Tailwind CSS v4 y DaisyUI. El backend utiliza ASP.NET Core Web API con Entity Framework Core y SQL Server.

¿Los libros y autores son reales?

Algunos títulos y autores mostrados pertenecen a obras reales, pero el catálogo fue creado únicamente para simular una tienda funcional.

¿Se pueden realizar compras?

No. Las funciones de carrito y autenticación son únicamente visuales y forman parte de la demostración técnica del proyecto.

¿Cuál es el objetivo del proyecto?

Mostrar habilidades de desarrollo frontend y backend, incluyendo consumo de APIs, paginación, filtros dinámicos, diseño responsive y arquitectura moderna para aplicaciones web.
